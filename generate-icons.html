Where to put the files


PWA (manifest)

  1. Save icon-512.png → assets/icon-512.png
  2. Save icon-192.png → assets/icon-192.png

Android launcher icons

  1. Open android/app/src/main/res/
  2. Replace ic_launcher.png and ic_launcher_round.png in each mipmap folder:

    mipmap-mdpi/ → 48 px files
    mipmap-hdpi/ → 72 px files
    mipmap-xhdpi/ → 96 px files
    mipmap-xxhdpi/ → 144 px files
    mipmap-xxxhdpi/ → 192 px files

Files labelled -round are the circular launcher variant (same icon, circular crop). Place them as ic_launcher_round.png in each folder.
